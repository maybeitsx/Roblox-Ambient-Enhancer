# Roblox Ambient Enhancer

A browser extension that improves Roblox’s visual atmosphere by enhancing ambient lighting, colors, and overall environment feel.

## ✨ Features
- Enhanced ambient lighting
- Better color balance
- Improved visual immersion
- Lightweight and fast

## 📦 Installation

### Chrome / Edge (Manual)
1. Download or clone this repository
2. Go to `chrome://extensions/`
3. Enable **Developer Mode**
4. Click **Load unpacked**
5. Select the extension folder

### Firefox
1. Go to `about:debugging`
2. Click **This Firefox**
3. Click **Load Temporary Add-on**
4. Select `manifest.json`

## 🚀 Usage
- Open Roblox in your browser
- The enhancer will automatically apply
